# Global Aviation Industry Exploratory Data Analysis (2010-2026)

## Overview
Comprehensive exploratory data analysis of the global aviation industry, merging airline financial data with route performance metrics to identify business model impacts on profitability, revenue trends, and operational efficiency.

## Dataset
- **Source:** Global Aviation Industry 2010-2026 (Kaggle)
- **Size:** 11,760 rows, 22 columns
- **Datasets Merged:** 
  - `airline_financials.csv` (revenue, operating margin, fleet data)
  - `route_performance.csv` (load factors, flight frequency, distance)

## Research Questions
1. How does revenue vary by geographic region?
2. Does business model (legacy vs. low-cost) correlate with operating margin?
3. What is the trend in load factor over time?
4. How does distance traveled correlate with average fare?
5. Does fleet size predict passenger volume?
6. How does region affect flight frequency?
7. Does margin correlate with passengers carried?
8. How has revenue shifted over the 2010-2026 period?
